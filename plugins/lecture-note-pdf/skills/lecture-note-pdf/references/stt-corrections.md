# STT 교정 사전 (누적)

자동 음성 인식 녹취에서 반복적으로 깨지는 기술 용어. 회차가 쌓일수록 여기에 누적한다.

**교정 원칙**
1. 교재에 있는 용어는 **교재 표기를 정본**으로 삼는다
2. 교재에 없으면 문맥으로 판단한다
3. 같은 용어가 발화마다 다르게 깨지므로 **변이형을 모두 모아 한 줄로** 정리한다
4. 노트 부록에 대조표를 넣되 **근거를 교재 페이지로 명시**한다

## 주의 — 교정하면 안 되는 것

강사 고유의 표현과 비유는 **그대로 살린다**. 이것이 노트의 가치다.

- "엔터 머신이 돼 있잖아" — 그대로
- "스킬 깎는 노인" — 그대로
- "방망이 깎던 노인" — 그대로
- "보따리장수처럼 들고 다닌다" — 그대로
- 회사·팀 내부 별칭(에이전트 이름 등) — 그대로 두되 첫 등장 시 각주
